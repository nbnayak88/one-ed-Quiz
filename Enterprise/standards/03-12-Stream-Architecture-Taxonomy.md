# 12-Stream Architecture Assessment Taxonomy — v0.1 (Proposed)

Architecture is the North Star. Every item has one primary architecture stream and may include up to three secondary streams.

| Stream | Core assessment lens |
|---|---|
| Enterprise | Strategy, portfolio coherence, target states, roadmaps |
| Business | Capabilities, value streams, stakeholders, business outcomes |
| Data | Governance, stewardship, quality, semantics and lifecycle |
| Application | Responsibilities, boundaries, modularity and maintainability |
| Technology | Technology quality attributes and fit-for-purpose choices |
| AI | Human oversight, data readiness, evaluation and responsible use |
| Security | Trust, identity, privacy, controls and resilience |
| UI/UX | Accessibility, usability, experience and adoption |
| Infrastructure | Availability, recovery, capacity and operability |
| Integration | Contracts, events, interoperability and reliable information flow |
| Domain | Domain rules, processes, operating models and outcomes |
| Industry | Sector economics, regulatory context and operating constraints |

**11 GICS sectors:** Energy; Materials; Industrials; Consumer Discretionary; Consumer Staples; Health Care; Financials; Information Technology; Communication Services; Utilities; Real Estate. Tag sector only when it materially changes context; otherwise mark cross-industry.

**Architecture reasoning sequence:** frame the business problem → map capability/value stream → establish constraints and requirements → generate options → evaluate relevant streams and trade-offs → justify decision and transition → specify outcomes and evidence.

TOGAF, BIZBOK and DAMA-DMBOK inform the conceptual foundations. This SuccessLabs taxonomy is an original operational adaptation, not a verbatim external framework. Streams and sectors are analytical tags, not multipliers of the 140,000-question target.
