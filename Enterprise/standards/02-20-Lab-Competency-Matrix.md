# 20-Lab Competency Matrix — v0.1 (Proposed)

Each Lab targets 1,000 original challenges in each of seven enterprise domains (7,000 per Lab). Labs are assessment engines, not separate technology product tracks.

| Lab | Assessment competency |
|---|---|
| 01 Discover | Problem framing, opportunity discovery, stakeholder needs |
| 02 Flow | Value streams, process analysis, constraints and improvement |
| 03 Design | Architecture principles, target state, option trade-offs |
| 04 Run | Operations, performance, resilience and service |
| 05 Build | Delivery design, implementation judgment and iterative execution |
| 06 Move | Transition architecture, modernization and migration risks |
| 07 Connect | Integration, interoperability and collaboration |
| 08 Validate | Evidence, quality, testing and benefits assurance |
| 09 Support | Root cause, service recovery and improvement |
| 10 Prove | Demonstrable competence, professional judgment and integrity |
| 11 Scale | Capability growth, learning and organizational scaling |
| 12 Influence | Communication, persuasion and negotiation |
| 13 Lead | Governance, accountability and prioritization |
| 14 Prototype | Hypothesis testing, experimentation and design thinking |
| 15 Evolve | Technology foresight, responsible AI and adaptability |
| 16 Share | Storytelling, insight synthesis and knowledge communication |
| 17 Document | Decision records, traceability and knowledge stewardship |
| 18 Engage | Empathy, facilitation, mentoring and conflict resolution |
| 19 Scan | Industry intelligence, trends and strategic foresight |
| 20 Innovate | Research, creativity and responsible value creation |

Each pairing is allocated four volumes of 250 questions. One primary Lab owns each question; secondary Lab relationships are tags, not duplicated content. Assessment forms include scenario MCQs, analytical judgments, option comparisons, architecture diagnosis, evidence interpretation, ethical dilemmas and rubric-scored challenges. Each Lab should adjust its question mix to its actual competency.

Seven domains: HR, CX, FI, SCM, PROC, BTM, LIT. Across domains, the question must be authentically contextualized rather than cosmetically renamed.
