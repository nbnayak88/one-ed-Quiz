# One-Ed Quiz · Class 1 Olympiad Question Bank

A subject-organized, progressively challenging Class 1 question bank.

## Class 1

**[Open the Class 1 learning index](Class-1/README.md)**

The master plan contains **10 Labs × 1,000 questions = 10,000 questions**, organized in **250-question Markdown volumes**, 25 questions per set, immediate answers and explanations, and a Super Olympiad Challenge per set.

> **Publication integrity:** Verified source Markdown volumes are published independently from missing material. The class index records actual published counts and does not equate a planned count with completed publication.

### Content principles
- Age-appropriate foundation-to-Olympiad reasoning.
- Preserve question-level explanations and four answer choices.
- Continuous, unique master-series IDs (Q1–Q10,000).
- Keep source content attributable to its original Lab and archive any numbering corrections in the README.
